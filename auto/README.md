# auto — данные об автомобиле по VIN и госномеру

Переиспользуемый клиент к apipoint.ru, по образцу `ads/direct.py`.

## Почему apipoint

Обзор рынка 07.08.2026 (103 агента, adversarial-проверка) дал один твёрдый вывод:
**дешевле 1,10 ₽ за опознание автомобиля не продаёт никто.** Все три кандидата на
суб-рублёвый прайс — avtovincod.ru, avtoproverka.com и слух про «ГИБДД по 0,80 ₽»
у api-cloud — при перепроверке развалились единогласно.

Выбор сделан не по цене, а по условиям входа:

| | apipoint | api-cloud | api-assist |
|---|---|---|---|
| принимает физлицо | **да, по оферте** | нет, только юрлица | — |
| абонплата | **нет** | 700 ₽/мес до 2000 запросов | нет |
| возврат остатка | **да, по заявлению** | не заявлен | — |
| цены опубликованы | **да, 63 метода** | частично | нет |
| вход по госномеру | через конвертер 1,20 ₽ | конвертер 1,70 ₽ | **не принимает** |

Госномер напрямую не принимает НИКТО на рынке — это свойство рынка, а не
поставщика. Отсюда продуктовый вывод: в форме просить VIN, госномер оставить
запасным вариантом (он дороже вдвое: 2,30 ₽ против 1,10 ₽).

## Устройство

Одна точка входа, метод выбирается полем `sources`:

```
POST https://apipoint.ru/api/call
Authorization: Bearer <токен>
{"sources": "vindecode", "vin": "..."}
```

**Ключевое свойство: в каждом ответе приходят `price` и `balance`.** Поэтому
расход виден по каждому вызову, и модуль пишет оба числа в журнал
`~/.config/digiterium/apipoint_calls.jsonl`. Фактическая себестоимость отчёта
берётся оттуда, а не из сметы.

Токен — `~/.config/digiterium/apipoint.env`, права 600. В переписке не хранится.

## Использование

```python
import apipoint as ap

ap.identify(vin="WBA11AD0305R89199")   # марка, модель, год, двигатель — 1,10 ₽
ap.identify(plate="Т114НК977")         # конвертация + декодер — 2,30 ₽
ap.risk_signals(vin)                   # ДТП + залог для превью — 1,70 ₽
ap.balance()                           # остаток
ap.spent_today()                       # потрачено за сегодня по журналу
```

`NoFunds` — отдельный тип исключения: исчерпание баланса это не сбой, а штатное
состояние, ретраить его бессмысленно, нужно приостановить проверки.

## Что ещё не измерено

`probe_billing.py` — запускать сразу после первого пополнения. Отвечает на
вопрос, которого нет ни в документации, ни в оферте: **тарифицируются ли опросы
готовности у асинхронного `reportjson`.** Заявленные 50 ₽ — это за отчёт или за
каждый из ~30 вызовов? Разница между 50 ₽ и полутора тысячами за отчёт, то есть
между рабочей моделью и закрытой нишей.

Попутно скрипт меряет, тарифицируется ли пустой ответ, и сверяет фактические
списания с прайсом.

```
python3 probe_billing.py [VIN]
```

Полный прогон стоит около 55 ₽, ста рублей хватит с запасом.

## Смета отчёта уровня Автокода

Разложено по блокам купленного отчёта Автокода (BMW X1, 07.08.2026):

- **27,60 ₽** — бюджетная сборка на кэш-методах
- **56,00 ₽** — рабочая, онлайн там, где важна свежесть
- **82,30 ₽** — плюс сервисная история у дилеров (`servicemaintenance`)

Готовый агрегированный `reportjson` — 50 ₽, но с неизвестной тарификацией
опросов. Розничная цена Автокода — 499 ₽ за отчёт, 113,98 ₽ в пакете из 50.

**Ловушка превью:** платить придётся за каждого посетителя, а не за покупателя.
При конверсии 1,6% превью за 2,80 ₽ даёт 175 ₽ на продажу и делает модель
убыточной. Превью должно стоить 1,10 ₽ — только `vindecode`, без риск-сигналов.

## Правовая рамка

Все российские поставщики этого рынка — мелкие ИП-перепродавцы, а не держатели
данных. В офертах они отрицают статус оператора госсистем, называют источник
«открытыми официальными источниками» и **контрактно перекладывают риск по 152-ФЗ
на интегратора**. Это не защищает: оператором персональных данных перед
регулятором становится тот, кто показывает данные конечному пользователю.

Отдельно: с 01.10.2024 оператором АИС ОСАГО стало АО «НСИС» со 100% участием
Банка России, РСА выбыл. Круг пользователей и тарифы заданы нормативно, поэтому
методы КБМ и ОСАГО по 0,50 ₽ у реселлеров — парсинг публичных проверок, а не
доступ по договору.
